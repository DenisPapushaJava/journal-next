# Заявки 2026.1.0-alpha.11

- **Карты HansLaser** — после расчёта карты раскроя для менеджера объединяются в один файл.
- **Папки цеха** — в «Станки и цены» можно задать имя папки для каждого станка. Несколько станков могут использовать одну папку.
- **Спецификации** — из расчёта открывается рабочий файл, из истории — сохранённая версия. Улучшено открытие архивных PDF по длинным путям в Windows.
