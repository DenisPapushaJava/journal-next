# Заявки 2026.1.0-alpha.20

- **Удалённая работа** — без связи можно создавать заявки и рассчитывать скачанные проекты. Когда связь вернётся, отправка в офис продолжится автоматически.
- **Резервная отправка** — если сервер недоступен, программа отправит расчёты через настроенную папку Яндекс Диска.
