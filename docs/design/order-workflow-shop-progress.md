# Ход отправки задания в цех

03.11.2026 начало подписи и копирования отмечается сразу перед await.
Ограниченный Feed обслуживает сведения о файлах; более ранний шаг не
откатывает текущий, Copying/Verifying принадлежат одному шагу. После возврата
копирования Feed останавливается до применения результата и записи частичных
отметок. Быстрый отказ и ожидание записи не оставляют неверный этап и не
затирают итог. Один прежний таймер, без дополнительных I/O.

02.11.2026 сведения о подписанных картах в итоге отправки: короткая сводка
«Карты: обновлено файлов N, без изменений M» и «Подробнее о картах».
Кнопка раскрывает в том же окне проект/имя файла, результат и использованную
подпись; для ошибки/неподтверждённой замены подпись не выдаётся за успешную.
Сохраняются прежние причины и путь резервной копии; ошибка передачи видна
и при раскрытых сведениях. Сводка считает файлы,
многостраничный документ не увеличивает количество файлов.

Данные — тот же массив MapSigningResult, возвращённый уже выполненным
подписанием; Caption ссылается на строку, уже переданную редактору.
Один проход для счётчиков после возврата, строка сводки сохранена. Нет
повторных чтений/обходов/хешей/SQL/Word и восстановления результата по файлам.
До раскрытия ItemsSource пуст; после — тот же массив без DTO/копии, список
виртуализирован и ограничен высотой. Повторное раскрытие не строит список
заново. Только метаданные, без хранения содержимого PDF/DOC. При новом
подборе/копировании прежний результат очищается; отменённое до возврата
подписание не получает выдуманную сводку. Обычный размер окна 560×380,
по явному раскрытию — высота до 580 DIP с ограничением рабочей областью
экрана существующим WindowSizing; ОК остаётся доступной.
Только локально в Next без публикации; основной Journal, живые данные,
схемы JSON15/MDB5/IPC1, подписи/копирование и релизные пути прежние.

02.11.2026 отправка в цех получила компактное окно хода работы 560×380 DIP
в обеих темах. По последнему уточнению 02.11.2026 появляется сразу для
каждой отправки, независимо от её длительности. Пять спокойных шагов: Проверка → Карты → Файлы →
Отметка → Текст. Текущие проект/файл/действие, счётчики обработанных файлов
при известном объёме; без общего процента/ETA. Многостраничный PDF/DOC — один
файл счётчика, страницы не выдаются за отдельные файлы. Области фиксированы,
имена переносятся/сокращаются с полной подсказкой, горизонтального скролла нет.

После успеха окно остаётся с итогом и кнопкой «ОК»: все пять шагов отмечены,
видно количество проектов и сводку выполненных действий. Итог также остаётся
в прежней строке заявки. После отмены или ошибки результат тоже ждёт «ОК».
Если нужен выбор комплекта, окно сменяется прежним экраном проверки. Ошибка
остаётся в окне до «ОК», без автоповтора. Отменить/Esc/крестик
только запрашивают отмену; окно не закрывается до возврата всей операции,
в том числе между подбором и копированием. При остановке показывается
понятное состояние и сохраняются уже готовые комплекты/подписанные карты.
Во время неотменяемой записи в буфер кнопка отмены отключена. Word ownership,
собственные процессы, подписи/backup/проверки/атомарное копирование прежние.

WorkflowShopProgress — типизированные события из уже идущих обходов/чтений/
подписи/копирования/проверки. Включены ГИБКА и сопоставление нескольких DSP.
Нет дополнительного сканирования/хеширования/SQL ради индикации. Счётчики
подписи увеличиваются после проверенного файла; копирование — после копии
и проверки хеша, неизменные комплекты считаются обработанными без перезаписи.
Это прогресс этапа, а не признак завершённой передачи/публикации.

WorkflowShopProgressFeed хранит только последнее событие. Один таймер 100 мс
только на текущую операцию и не более одного ожидающего UI-callback;
100 000 сообщений не создают 100 000 обновлений интерфейса. Этапы/названия
не меняют состав таблиц/черновики и не вызывают обновление списка заявок.
Таймер останавливается/освобождается в using, поздние события игнорируются;
перед отметкой/буфером лента файлов уже остановлена. Индикатор — обычный
ProgressBar, без тяжёлых эффектов и отдельного журнала всех файлов.

Документы/имена путей/JSON15/MDB5/IPC1/цены/релизные каналы прежние. Только
локально в Next без commit/push/PR/релиза; основной Journal и живые данные
не менять. Нативный Windows/Word/SMB в этом этапе отдельно от managed тестов.
