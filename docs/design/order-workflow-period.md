# Период списка заявок

Состояние на 02.11.2026. Период — отбор по локальной дате **создания**
заявки, а не изменения или спецификации. Существующая сортировка по
UpdatedAt/номеру остаётся прежней.

В левой панели прежние «Сегодня» → календарь → «Все даты». Календарь
сохраняет выбор дня и навигацию по месяцам/годам; в режиме дней добавлена
кнопка «Весь месяц». Она выбирает месяц, открытый в календаре, и закрывает
всплывающую панель. Название периода, например «Октябрь 2026», видно на
кнопке и в счётчике списка; все дни месяца выделены при повторном открытии.
Простое перелистывание/выбор года не применяет фильтр; Esc отменяет просмотр.
При клике по дню выбирается именно один день, даже если его дата совпадает
с первым числом текущего месячного фильтра. Сегодня/Все даты снимают режим
месяца. Месяц не сохраняется как новая настройка запуска.

Дата и режим применяются одним PeriodSelected, а не двумя независимыми
двусторонними привязками: нет промежуточного запроса за первый день. Для
прежнего одиночного режима WorkflowDatePicker поддерживает SelectedDate,
выбор месяца явно разрешён только у периода списка. Обработчик окна тонкий;
отбор, загрузка и сохранение карточек остаются в существующей модели.

Месяц объединяется с поиском и быстрыми условиями через AND. Сброс быстрых
фильтров оставляет период/поиск. Пустая выборка называет месяц. Карточка вне
периода и её черновики сохраняются по действующему контракту навигации;
смена периода не записывает и не сбрасывает их. При смене день↔месяц с
одинаковой датой устаревшее контекстное меню также закрывается.

Для MDB используются прежние From/Until WorkflowReadQuery: локальное начало
месяца включительно и начало следующего исключительно. Каждая граница
отдельно переводится в UTC (в том числе при переходе часового пояса/DST).
Существующий SQL с параметрами created_at>=? AND created_at<? применяется
до TOP, COUNT и курсора. Month/Year вокруг столбца и полная загрузка БД
не добавляются. Страницы/поколения/отмена/удержание открытых ID прежние.
Для декабря 9999 Until отсутствует, чтобы не вычислять несуществующий 10000 год.
JSON-хранилище отбирает уже прочитанные заявки по локальному году/месяцу.

Нет новых пакетов, таймеров, подписок, схем, индексов или IPC-полей. Основной
Journal, пользовательские данные и релизные пути не меняются. Нативные
Windows UI/Jet/SMB отдельно от managed/headless проверок.
