# Библиотека поддержки

Контролируемая копия общих компонентов Journal на момент отделения Next.
Содержит используемые контролы, темы, парсинг представления, буфер и модель
обновлений. OutputType=Library; прежние Program/App удалены, отдельный Journal
не собирается и не запускается. Пространства имён и AssemblyName сохранены
для совместимости XAML-ресурсов. Это не ссылка на checkout другого продукта.
