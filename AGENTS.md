# Journal Next

Отдельный новый продукт, публичный репозиторий DenisPapushaJava/journal-next.
Рабочая папка /home/denis/Myprojects/journal-next. Прежний Journal остаётся
в /home/denis/Myprojects/journal и journal-v2.0; его файлы, remote, ветки,
релизы и профиль не изменять. Автоматического обмена изменениями нет.

24.10.2026 пользователь поручил первый Windows-выпуск Journal Next
2026.1.0-alpha.1: отдельный репозиторий, CI, установщик и обновления.
Для этого этапа разрешены коммиты, push и публикация после проверок.
Описание изменений для колокольчика первого выпуска оставить пустым.

Стабильные идентификаторы: PackageId DenisPapusha.JournalWorkflow,
профиль JournalWorkflow, канал workflow-win-x64, теги workflow-v…,
EXE Jornal.Workflow.Desktop.exe. Имя UI Journal Next независимо от них.
Выпуски только Windows x64, Access-хост x86 внутри при необходимости.
Никаких ссылок на feed/package старого Journal. Исходная MDB только источник
цен, её схему/данные не менять. Новое хранилище пока локальный JSON-прототип;
общий Access не объявлять реализованным.

src/Journal.Compatibility — контролируемая копия компонентов прежней
программы, библиотека без старой точки входа. Дальнейшие изменения здесь
относятся только к Journal Next. Исходная история сохранена отдельно.

Перед выпуском обязательны локальная сборка/тесты, Windows CI, упаковка,
реальная установка OfflineSetup, запуск установленного AccessHost,
обновление/перезапуск через отдельный канал и сохранность профиля/данных,
проверка четырёх файлов/хешей/публичного feed. Неизвестный исход записи не
повторять автоматически. Первый опубликованный выпуск не перезаписывать.

Функции/UX: docs/order-workflow-development.md, docs/order-workflow-feedback.md
и docs/design/order-workflow-*.md. Принимаем только согласованные изменения;
сейчас будущая UX-доработка — проверка комплектности заявки с переходом к
позиции. Прочие предложенные функции пока отложены.
